Guides / Theming

Swapping themes at runtime

One attribute flip restyles the whole app.

Load every theme

Import @lepid-labs/styles/all once. Every rule is scoped by data-ld-style, so the themes coexist without leaking into each other.

import "@lepid-labs/styles/all";

Flip the attribute

Set data-ld-style on <html>, or on any container to theme just that subtree. The shell repaints its background from the new theme's .ld-bg treatment.

document.documentElement.dataset.ldStyle = "summer-cloud";
Fonts are not bundled — read the URLs from @lepid-labs/styles/manifest.

Persist the choice

Store the name and re-apply it before first paint to avoid a flash. Validate it against the manifest so a removed theme falls back cleanly.
